# 概率与分布

> 概率是模型用来表达不确定的语言。

**Type:** Learn
**Language:** Python
**Prerequisites:** Phase 1，第 01–04 课
**Time:** ~75 分钟

## 学习目标

- 从零写出 Bernoulli、Categorical、Poisson、均匀分布和正态分布的 PMF 或 PDF
- 计算期望和方差，并用中心极限定理说明高斯分布为什么到处出现
- 写出数值稳定的 softmax 和 log-softmax：先减去最大的 logit
- 从 logits 算出交叉熵，并把它和负对数似然接上

## 问题

分类器打出 `[0.03, 0.91, 0.06]`。语言模型从五万个候选里选下一个词。扩散模型从学到的分布里抽样，生成图像。这些都是概率。

模型的每一次预测都是一个分布。每一个损失函数都在量「预测的分布离真实分布有多远」。每一次更新都在把一个分布拧得更像另一个。没有概率，论文读不懂，模型查不出错，训练损失变成 NaN 时也不知道为什么。

## 概念

### 事件、样本空间、概率

样本空间 S 是所有可能结果的集合。事件是样本空间的一个子集。概率把事件映成 0 和 1 之间的数。

```text
抛硬币：
  S = {正面, 反面}
  P(正面) = 0.5，P(反面) = 0.5

掷一颗骰子：
  S = {1, 2, 3, 4, 5, 6}
  P(偶数) = P({2, 4, 6}) = 3/6 = 0.5
```

三条公理撑起全部概率：

1. 任何事件 A，`P(A) >= 0`
2. `P(S) = 1`，总有一件事发生
3. A 和 B 不能同时发生时，`P(A 或 B) = P(A) + P(B)`

贝叶斯、期望、各种分布，都从这三条推出来。

### 条件概率和独立

`P(A|B)` 是「已经知道 B 发生了，A 的概率」。

```text
P(A|B) = P(A 且 B) / P(B)

一副牌：
  P(是国王 | 是人头牌) = (4/52) / (12/52) = 4/12 = 1/3
```

人头牌有 12 张：J、Q、K 各 4 张。其中国王 4 张。知道「是人头牌」之后，样本空间从 52 张缩成 12 张。

两个事件独立，是指知道一个，对另一个没有新信息：

```text
独立：     P(A|B) = P(A)
等价写法： P(A 且 B) = P(A) * P(B)
```

连续抛硬币是独立的。一副牌不放回地抽，不是独立的：抽走一张国王，下一张还是国王的概率变了。

### 质量函数和密度函数

离散随机变量有概率质量函数 PMF。每个结果有一个可以直接读的概率。

```text
公平骰子：
  P(X = 1) = 1/6
  ...
  P(X = 6) = 1/6
  全部加起来 = 1
```

连续随机变量有概率密度函数 PDF。单个点上的密度不是概率。概率是密度在一段区间上的积分。

```text
P(a <= X <= b) = 从 a 到 b 对 f(x) 积分

f(x) 可以大于 1（它是密度，不是概率）
从负无穷积到正无穷必须等于 1
```

分类输出是 PMF：在有限个类别里选一个。VAE 的隐空间用 PDF：那里的量是连续的。

### 常见分布

**Bernoulli：** 一次试验，两个结果。二分类。

```text
P(X = 1) = p
P(X = 0) = 1 - p
均值 = p，方差 = p(1-p)
```

**Categorical：** 一次试验，k 个结果。多分类，也就是 softmax 的输出。

```text
P(X = i) = p_i，并且所有 p_i 加起来是 1
例：P(猫) = 0.7，P(狗) = 0.2，P(鸟) = 0.1
```

**均匀：** 每个结果一样可能。随机初始化会用到。

```text
离散：P(X = k) = 1/n
连续：在 [a, b] 上 f(x) = 1/(b-a)
```

**正态：** 钟形曲线。参数是均值 mu 和方差 sigma²。

```text
f(x) = (1 / sqrt(2*pi*sigma²)) * exp(-(x-mu)² / (2*sigma²))

标准正态：mu = 0，sigma = 1
  大约 68% 的质量落在 1 个 sigma 内
  大约 95% 落在 2 个 sigma 内
  大约 99.7% 落在 3 个 sigma 内
```

**Poisson：** 固定区间里稀有事件发生的次数。

```text
P(X = k) = (lambda^k * e^(-lambda)) / k!
均值 = lambda，方差 = lambda
```

### 期望和方差

期望是用概率加权的平均结果。

```text
离散：E[X] = 所有 x_i * P(X = x_i) 的和
连续：E[X] = x * f(x) 的积分
```

方差量的是散开的程度。

```text
Var(X) = E[(X - E[X])²] = E[X²] - (E[X])²
标准差 = sqrt(Var(X))
```

损失就是数据分布上的期望。梯度方差大，训练就吵。

### 联合分布和边缘分布

`P(X, Y)` 同时描述两个变量。下面这张表里，天气和带不带伞：

| | 不带伞 | 带伞 | 边缘 P(天气) |
|---|--------|------|----------------|
| 晴 | 0.40 | 0.10 | 0.50 |
| 雨 | 0.05 | 0.45 | 0.50 |
| 边缘 P(伞) | 0.45 | 0.55 | 1.00 |

边缘分布是把另一个变量加掉：

```text
P(X = x) = 对所有 y 把 P(X = x, Y = y) 加起来
```

行和、列和就是边缘。

### 正态分布为什么到处都是

中心极限定理：很多独立随机变量的和或平均，不管原来每个是什么分布，都会靠近正态。

```text
掷 1 颗骰子：平的
2 颗的平均：中间高、两边低
30 颗的平均：很接近钟形
```

所以测量误差近似正态，网络权重常用正态初始化，SGD 里很多样本梯度加在一起也近似正态。给定均值和方差时，正态还是熵最大的那个分布。

### 对数概率

很多很小的概率乘在一起，会下溢成 0。

```text
P(句子) = 0.01 * 0.003 * 0.02 * ...  → 大约 30 项之后变成 0.0
log P(句子) = log(0.01) + log(0.003) + ...  → 仍是有限的负数
```

规则：

- `log(a * b) = log(a) + log(b)`
- 概率在 `(0, 1]` 里，对数 `<= 0`
- 更负 = 更不可能
- 交叉熵就是正确类别的负对数概率

### Softmax

网络打出的是没有归一化的分数，叫 logits。softmax 把它们变成合法的分布：

```text
softmax(z_i) = exp(z_i) / 所有 exp(z_j) 的和
```

输出都在 `(0, 1)`，加起来是 1，原来谁大谁还大。`exp` 会把差距放大。

先减去最大的 logit，避免溢出：

```text
z = [100, 101, 102]
exp(102) 溢出

z - max(z) = [-2, -1, 0]
exp(0) = 1
```

分子分母都少乘了 `exp(最大值)`，约分之后概率不变。log-softmax 把 log 和这一步合在一起。PyTorch 的交叉熵内部用的就是它。

### 抽样

从分布里抽出随机数。Dropout 抽哪些神经元关掉。语言模型从预测分布里抽下一个词。扩散模型抽噪声再逐步去掉。从任意分布抽样，会用到逆变换、拒绝采样，或 VAE 里的重参数化。

## 术语

| 术语 | 它实际指什么 |
|------|----------------|
| 样本空间 | 一次试验全部可能结果的集合 S |
| PMF | 离散结果的概率，全部加起来是 1 |
| PDF | 连续变量的密度。在区间上积分才是概率。单点密度可以大于 1 |
| 条件概率 | `P(A\|B) = P(A 且 B) / P(B)` |
| 独立 | `P(A 且 B) = P(A) * P(B)`。知道一个，对另一个没有新信息 |
| 期望 | 用概率加权的平均。损失就是一个期望 |
| 方差 | 离均值的平方偏差的期望。大表示估计吵、不稳定 |
| 正态分布 | 钟形。中心极限定理让它到处出现 |
| 中心极限定理 | 很多独立样本的平均，会靠近正态，不管原来是什么分布 |
| 联合分布 | `P(X, Y)`，每一对结果的概率 |
| 边缘分布 | 把另一个变量加掉，剩下一个变量自己的分布 |
| 对数概率 | `log P(x)`。乘法变加法，长序列不会下溢成 0 |
| Softmax | 把 logits 变成加起来等于 1 的正数 |
| 交叉熵 | 真实分布和预测分布差多远。分类时化成正确类别的 `-log q` |
| Logits | softmax 之前的原始分数 |
| 抽样 | 按分布抽出随机值。模型生成输出就是在抽样 |
